# Permission to share LEKMOD's code

LEKMOD's license requires written permission from EnormousApplePie before any file containing their code is shared. The release DLL is built from LEKMOD's source, and the `lekmod-*.patch` files carry some of it.

EnormousApplePie gave that permission on 2026-10-28, over Discord, for the DLL to be published on GitHub as lekmod-bazaar: free, open source and credited to them.
